Política de Acceso

Alcance

Ingresos por parte de personal de operadores, sus contratistas y subcontratistas. El procedimiento deberá cumplirse para cada ingreso.

Procedimiento

El requisito para autorizar el ingreso es la carga de un ticket aquí por parte de personal del operador, para que podamos llevar el control y seguimiento, informar adecuadamente al propietario y asignar los permisos necesarios en el sistema de candados electrónicos.

En el mismo se requiere completar:

  • Datos de quien carga el ticket:
    • Nombre completo
    • Correo electrónico (con dominio del operador)
    • Teléfono
  • ID del sitio al que deben ingresar. De no conocer el ID del sitio pueden consultarlo aquí con el ID del operador o la dirección.
  • Cliente u operador
  • Motivo “Acceso”
  • Franja de fechas y horarios del ingreso
  • Detalle del personal que debe ingresar incluyendo de cada uno:
    • Nombre completo
    • DNI
    • Teléfono (necesario para que puedan utilizar la app que acciona los candados electrónicos)
  • Detalle de las tareas a realizar
  • Link público a una carpeta virtual (GoogleDrive, Dropbox, OneDrive, etc.) que contenga la siguiente documentación:
    • Para empleados:
      • ART con CNR
      • SVO
      • F931 y comprobante de pago
    • Para autónomos:
      • Seguro de accidentes personales con CNR
      • Pago de monotributo

Una vez generado el ticket recibirá un correo a la dirección indicada con el número de referencia y un enlace para el seguimiento del mismo. Una vez revisada la documentación se actualizará el ticket y será notificado al mismo correo, ya sea por la aprobación o solicitando alguna rectificación.

El plazo de respuesta será de 48hs hábiles.

Llaves

Los sitios pueden tener candados comunes o bien electrónicos. Para los comunes, como procedimiento regular se entrega un juego de llaves al supervisor del Operador que realiza la recepción de la obra, por lo cual los contratistas y subcontratistas del Operador deben realizar el procedimiento estándar del Operador para obtener la llave. Los candados electrónicos se accionan a través de la app WiKey para Android o iOS. Para ello se requiere un usuario que se creará al solicitar el primer ingreso de cada persona. En esta instancia se adjuntarán las credenciales e instructivos correspondientes en el propio ticket
