### Hola!
Esta es una versión pública de una aplicación web desarrollada para una compañía de telecomunicaciones. El objetivo principal es gestionar reclamos y pedidos de acceso de los clientes.
También funciona como base de datos centralizada para el área de operaciones, recogiendo la información de la infraestructura, clientes, informes de mantenimiento preventivo, suministros eléctricos, etc.

El backend está desarrollado en Python sobre Django y una base de datos SQL (sqlite3 en este caso, MySQL en producción).
EL frontend está basado en templates de Django, con Javascript puro para las funciones dinámicas y HTMX para manejar el comportamiento asincrónico.
Para ilustrar el comportamiento, pueden acceder a una [demo](https://tickets-o7q6.onrender.com) con datos ficticios. Las llamadas a APIs externas de proveedores de la empresa fueron eliminadas por privacidad.

### Hi!
This is a public version of a web application developed for a telecommunications company. Its main purpose is to manage customer complaints and access requests.
It also functions as a centralized database for the operations department, collecting information on infrastructure, customers, preventive maintenance reports, power supplies, etc.

The backend is developed in Python using Django and an SQL database (SQLite3 in this case, MySQL in production).
The frontend is based on Django templates, with plain JavaScript for dynamic functions and HTMX to handle asynchronous behavior.
To illustrate how it works, you can access a [demo](https://tickets-o7q6.onrender.com) with fictitious data. Calls to external APIs from the company’s providers have been removed for privacy reasons.
